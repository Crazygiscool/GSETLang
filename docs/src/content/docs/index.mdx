## ⚡ What is GSET?

GSET (**Generic Syntax Extension Tool**) is a **single-binary transpiler**. You write your program once in a small, procedural, syntax-familiar language — braces, `print`, `if`, `for`, `while`, `function` — and GSET rewrites it into real, runnable source code for one of five supported targets.

<CardGrid stagger>
  <Card title="🎯 Five Working Targets" icon="rocket">
    Python, JavaScript, Go, Java, and Ruby backend emitters. Each one generates a complete runnable file with correct wrappers and builtins.
  </Card>
  <Card title="🔧 Configurable Keywords" icon="setting">
    `gset.conf` maps aliases like `say` and `shout` to each target's real print function. Custom keywords genuinely change the output.
  </Card>
  <Card title="🐛 No Frozen Parser" icon="check-circle">
    `match`/`case`, `try/catch`, and list comprehensions parse and transpile without spinning the CPU.
  </Card>
  <Card title="🛠️ Single Binary, Zero Dependencies" icon="packages">
    One static Go binary. The only runtime you need is whichever target you want to execute.
  </Card>
</CardGrid>

## 🚀 The 30-Second Example

Write `hello.gset`:

```gset
var name = "World"
var count = 3
print("Hello, " + name)
while count > 0 {
    print(count)
    count = count - 1
}
```

Now run it on three different runtimes. Same file, no changes:

```bash
$ gset run hello.gset --target python
Hello, World
3
2
1

$ gset run hello.gset --target javascript
Hello, World
3
2
1

$ gset run hello.gset --target go
Hello, World
3
2
1
```

Here is exactly what GSET generates (streamlined for readability — real output is formatted per target):

```
# --target python                          // --target javascript            // --target go
name = "World"                             let name = "World"                package main
count = 3                                  let count = 3                     import "fmt"
print("Hello, " + name)                    console.log("Hello, " + name)
while count > 0:                           while (count > 0) {               func main() {
    print(count)                               console.log(count)                fmt.Println("Hello, " + name)
    count = count - 1                          count = count - 1                 for count > 0 {
                                                  }                                    fmt.Println(count)
                                                                                      count = count - 1
                                                                                  }
                                          }
```

## 💡 Why GSET?

| | Benefit |
|---|---------|
| 💻 **A small, learnable language** | One syntax to write, not a mental fork of five languages |
| ⚙️ **Portable logic** | Loops, branches, functions, arrays, and maps move between runtimes |
| 🎓 **Language learning** | See the same program written the "Python way" and the "Go way" side by side |
| 🔧 **Honest limits** | Each target page documents exactly what compiles and what does not |
